# Multimodal System

Welcome to the **Multimodal System** developed by **A&J**. This platform provides a variety of functionalities, including:

- **DeepFace Analysis**: Perform advanced facial analysis.
- **English to Hindi-Gujarati Translator**: Translate English text into Hindi and Gujarati.
- **Stock Market Price Checker**: Get real-time stock market prices.
- **Enhanced Hand Detection Program**: Detect hands with enhanced precision.
- **Hand Tracking & Brightness Control System**: Control brightness using hand tracking.
- **Advanced Image Analyzer**: Analyze images with advanced algorithms.

---

## Features

1. **Interactive User Interface**: Built using Streamlit for ease of use.
2. **Multimodal Functionality**: Choose from multiple models and perform various tasks.
3. **Dynamic Background**: Enjoy a visually appealing interface with gradient animations.
4. **Modular Design**: Each functionality is implemented in separate modules for better organization.

---

## Prerequisites

Ensure that the following software is installed on your system:

- **Python**: Version 3.8 or higher

Install the required libraries using the commands below.

---

## Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/your-repository/multimodal-system.git
   cd multimodal-system
   ```

2. **Install Dependencies**:

   Upgrade `pip`:

   ```bash
   python -m pip install --upgrade pip
   ```

   Install the required Python libraries:

   ```bash
   pip install numpy
   pip install pandas
   pip install pillow
   pip install torch
   pip install transformers
   pip install opencv-python
   pip install mediapipe
   pip install screen-brightness-control
   pip install yfinance
   pip install googletrans==4.0.0-rc1
   pip install deepface
   pip install retinaface
   pip install streamlit
   pip install streamlit-lottie
   pip install tf-keras
   ```

---

## How to Run the Code

1. **Navigate to the Project Directory**:

   ```bash
   cd path-to-project-directory
   ```

2. **Run the Application**:

   Execute the following command in the terminal:

   ```bash
   streamlit run Multimodal.py
   ```

3. **Explore the Features**:

   - Open the URL displayed in the terminal (usually `http://localhost:8501`).
   - Choose any modal from the interface and start exploring.

## Modules

Each modal corresponds to a specific functionality and is implemented in a separate Python module:

- `Multimodal1`: DeepFace Analysis
- `Multimodal2`: English to Hindi-Gujarati Translator
- `Multimodal3`: Stock Market Price Checker
- `Multimodal4`: Enhanced Hand Detection Program
- `Multimodal5`: Hand Tracking & Brightness Control System
- `Multimodal6`: Advanced Image Analyzer
